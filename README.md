# Pip's Chestnut Roast

Help Pip catch warm falling chestnuts to feed the cosy glowing fireplace in Loki's arcade corner. Watch out for chilly icicles that might cool down your streak!

**How to play:** Use Arrow Keys or Left/Right touch buttons to move Pip.

▶️ Play it: https://lokistown.github.io/games/pips-chestnut-roast/
